# Doc2FAQ

Doc2FAQ is a Java web application designed to provide the foundation for converting documents into frequently asked questions (FAQs).

## Project Status

Initial project setup.

## Technology Stack

- Java
- Spring Boot
- Maven or Gradle
- Spring Web

## Getting Started

Build and run instructions will be added when the initial Spring Boot application is generated.

## Planned Features

- Document ingestion and processing
- Automatic FAQ generation
- Web-based user interface
